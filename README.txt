FrameBot — мод для Geometry Dash (Geode)

Сборка: установить Geode SDK + CLI, затем:
  geode build
(получится .geode файл, положить в папку geode/mods)

Использование (в уровне, панель слева внизу):
1. Выберите кружок-окно (9-12, 7-8, 5-6, 4, 3, 2, 1, X).
2. Нажмите Rec и проходите уровень. Каждый ваш прыжок сохраняется
   на том кадре и в том месте, где вы нажали, с цветным кружком выбранного окна.
   Менять кружок можно прямо во время прохождения.
3. Прошли уровень -> реплей сохраняется автоматически.
4. Включите Video, нажмите Play: бот повторит клики, видео пишется в
   папку сохранений мода (<уровень>.mp4). Нужен ffmpeg в PATH (Windows).
Off — выключить бота.
